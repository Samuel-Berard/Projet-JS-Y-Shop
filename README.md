# Y-Shop

Bienvenue sur **Y-Shop**, votre boutique en ligne dédiée aux Fruits du Démon de l'univers One Piece. Explorez, découvrez et procurez-vous les fruits les plus rares et puissants du Grand Line !

## Fonctionnalités

*   **Boutique de Fruits du Démon** :
    *   Navigation par catégories.
    *   Affichage des détails complets de chaque fruit .
*   **Favoris** :
    *   Ajoutez vos fruits préférés à votre liste de favoris.
    *   Visualisez rapidement vos produits sauvegardés.
*   **Panier et Commande** :
    *   Ajoutez des fruits à votre panier.
    *   Système de commande avec récapitulatif total.
*   **Design One Piece** :
    *   Interface utilisateur inspirée de l'univers One Piece.

## Installation

1.  **Cloner le dépôt** :
    ```bash
    git clone <url-du-dépôt>
    cd Projet-JS-Y-Shop
    ```

2. **demarrage du serveur** :
    ```bash
    cd backend
    npm install
    npm start
    ```

3. **demarrage du client** :
    ```bash
    cd frontend
    npm install
    npm start
    ```
