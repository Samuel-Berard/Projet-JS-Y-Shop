# 🏴‍☠️ La Boutique du Naufragé 🌊

Bienvenue sur **La Boutique du Naufragé**, l'unique boutique clandestine dédiée aux **Fruits du Démon** de l'univers de *One Piece*. Explorez, découvrez et procurez-vous les fruits les plus rares et puissants de Grand Line ! 🍈✨

## ✨ Fonctionnalités

*   🛒 **Boutique de Fruits du Démon** :
    *   Navigation intuitive par catégories (Paramecia, Zoan, Logia).
    *   Affichage des détails complets et des pouvoirs de chaque fruit.
*   ❤️ **Favoris** :
    *   Ajoutez vos fruits préférés à votre liste de souhaits.
    *   Visualisez rapidement vos produits sauvegardés pour ne rater aucune occasion.
*   🛍️ **Panier et Commande** :
    *   Ajoutez des fruits à votre panier en un clic.
    *   Système de commande fluide avec récapitulatif total de vos Berrys.
*   ☠️ **Design One Piece** :
    *   Interface utilisateur immersive, totalement inspirée de l'univers de pirates.

## 🛠️ Prérequis

Avant de hisser les voiles, assurez-vous d'avoir installé les outils suivants :
*   [Node.js](https://nodejs.org/) (qui inclut npm)
*   [Git](https://git-scm.com/)

## 🚀 Installation et Démarrage

1.  **Cloner le dépôt** :
    ```bash
    git clone https://github.com/Samuel-Berard/Projet-JS-Y-Shop.git
    cd Projet-JS-Y-Shop
    ```

2. **Démarrage du serveur (Backend)** :
    ```bash
    cd backend
    npm install
    npm run start:back
    ```

3. **Démarrage du client (Frontend)** :
    *(Ouvrez un nouveau terminal pour cette étape)*
    ```bash
    cd frontend
    npm install
    npm run start:front
    ```

4. **Accéder au site** :
    Rendez-vous sur votre navigateur web via l'une des adresses suivantes :
    ```text
    http://192.168.1.253:5500
    http://127.0.0.1:5500
    ```
